Automatic saving (this browser)

Every change is saved into this browser's storage moments after you make it, and the app reopens from that save. It lives in this browser on this PC only - it does not travel with the HTML file. To move machines, share, or keep an offline copy, use Save workspace and import the file on the other side.
One editor at a time: two open tabs of this app in the same browser overwrite each other's autosaves, silently. Clearing the browser's site data deletes the stored plan - keep an exported workspace file as your off-browser copy.

How this works

Scheduling logic
Pick a main category and a value band and the app looks up the standard lead time, then splits it across RFP issue, Job-Ex, technical bid opening, technical evaluation, commercial evaluation, TER award and contract signature. SOW, cost estimate, PR issue, ExCom, Board and NTP use the fixed durations on the Lead Times tab. Enter one baseline start date and every downstream baseline date cascades from it — each stage starts the day after the one before finishes, exactly as your workbook does.
Status and forecast
A stage is complete once it has an actual finish, in progress once it has an actual start, otherwise not started. Forecast dates re-cascade from the last actual date recorded, so a slip early in the cycle carries through to the NTP date. Package health compares forecast NTP with baseline NTP — on track at or ahead of baseline, at risk up to 14 days late, delayed up to 30, critical beyond that.
Value bands
Bands are read in SAR millions. The app suggests the band from the estimated budget and flags any package where the recorded band does not match the value — those appear under data quality checks.
